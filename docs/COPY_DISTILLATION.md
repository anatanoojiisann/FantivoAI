# Mini App 文案精简记录

## 目标

减少不帮助用户完成当前任务的文字，让首页发现、创作、作品和充值四条流程更直接。支付、安全、成本、退款、状态和错误恢复信息不在删除范围内。

## 已移除或收敛

- 顶部品牌副标题 `VIDEO STUDIO`。
- 首页、作品页和钱包页的装饰性眉题。
- 所有页面底部的品牌与 Telegram 署名。
- 创作页主按钮下方长期占位的成本与退款说明；确切成本仍显示在按钮中，退款仍随任务状态显示。
- 钱包营销标题、介绍段落、重复的订阅/一次性购买标签和底部支付实现说明。
- 订阅卡的泛化营销描述，只保留计划名、周期、价格、积分和动作。
- Feed 分类与分组中的项目数量徽标。
- 内容详情的分类眉题、通用占位描述和内部模型标识；真实内容描述仍会显示。
- 作品列表中的任务 ID，改为“文生视频 / 图生视频”；任务 ID 只保留在详情中。
- 任务详情中的更新时间、开始时间、重复状态、完成任务的 100% 进度、供应商模型、Seed、音频关闭和“未退款”。
- 中文界面中的 `credits` 混排，统一为“积分”。

## 保留的信息

- Prompt、素材要求、画面比例、时长、清晰度、模型与实际成本。
- 任务状态、进行中进度、取消、失败原因、退款结果与恢复动作。
- 条款与隐私同意、30 天自动续费、Stars 价格和每周期积分。
- 支付、创建、取消、发布等动作的即时成功或失败反馈。
- 空状态和区域失败中的下一步操作。

## 后续观察

- 首页分类数量移除后，分类切换率是否下降。
- 作品卡从任务 ID 改为创作类型后，详情打开率是否更稳定。
- 创作页说明移除后，因成本或退款产生的支持请求是否增加。
- 钱包精简后，从进入钱包到勾选条款、发起 invoice 的完成率是否提升。
